# Claude Workflow

Always work milestone by milestone.

Never implement multiple milestones.

Never redesign unrelated code.

Always preserve architecture.

Always keep backward compatibility unless explicitly instructed otherwise.

Before coding:

- inspect existing architecture
- identify affected files
- explain implementation plan

After coding:

- flutter analyze
- flutter test

Always produce:

- Modified files
- Verification results
- Deployment requirements
- Architectural recommendations

Stop and wait for approval.
